# Public product pattern review

Public first-party pages reviewed on 2026-09-06. This is a scope/design input, not a hands-on audit of paid products. No protected lessons, ranges, strategy data or graphics were copied.

| Product | Observed public patterns | Useful principle for this release |
| --- | --- | --- |
| [GTO Wizard](https://gtowizard.com/) | Study, practice and analysis as connected jobs; configurable drills; immediate EV feedback; solution library and learning resources | Preserve context from lesson to exercise, then show action frequencies and EV evidence together |
| [Pokercode](https://www.pokercode.com/) | Learning library, masterclasses, quizzes, preflop trainer and separate community/coaching navigation | Give the lesson a clear learning objective and direct next exercise; separate learning from tools |
| [DTO](https://www.dto.poker/) | Public page returned a browser-verification challenge | No product claims inferred and no bypass attempted |

Subscription prices and promotional claims were intentionally not used as architecture inputs. Mobile usability and authenticated workflows were not verified for these external products. The Rangeform UI is original, with a compact study workspace and a focused mobile trainer. No third-party dataset is required.
